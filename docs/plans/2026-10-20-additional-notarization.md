# 同一签名包的补充公证与恢复

目标：按用户授权为 v1.1.3 arm64 原始签名 DMG 新增一次申请，并允许新旧任一申请通过后发布。

设计：本机负责一次显式上传和回执保存；CI 输入只导入已有 ID，不新增上传。归档 state 拥有候选集合，
20 分钟内查询全部候选，选中 Accepted 的 ID 作为既有后处理输入。保持原始 tag、构建和签名不变。

1. 更新签名 spec 和恢复文档，明确候选所有者、哈希校验、幂等导入和失败规则。
2. 在 resumableMacNotarization 测试中先添加新旧任选通过、错误隔离、限时续查和拒绝错误包的失败用例。
3. 实现候选导入与查询；workflow 添加已有 ID 输入，并在提交 checkpoint 前导入。
4. 运行相关 Vitest、架构、typecheck、lint、格式与 actionlint；提交推送维护分支。
5. 下载并核验原始归档，一次性上传同一 DMG，保存完整回执；导入新 ID 启动真实恢复发布。
6. 更新本地发布状态与跟进指令，保留新旧 ID，后续只查询不重复提交；成功后完成原有发布验收。
