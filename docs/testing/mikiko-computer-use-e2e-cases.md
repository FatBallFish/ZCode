# Mikiko Computer Use 桌面验收用例

正式集成已由用户批准纳入v1.1.4，使用仓库WDIO隔离profile、当前源码构建和已签名的自有原生Helper。以下case接受，作为pending内部验收执行，不未经人工review自动晋升Docker/CI。

| Case   | 前置                                    | 操作                                                                          | 断言                                                                                            |
| ------ | --------------------------------------- | ----------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| CU-E01 | macOS14+、真实随包资源、全新隔离profile | 打开电脑控制设置                                                              | 默认关闭；没有权限/重启操作；不自动请求OS授权                                                   |
| CU-E02 | 同上，Helper自身两项权限由用户已授权    | 开启插件、查看状态、重启空闲Helper、开启composer入口、切换窄屏/主题、关闭插件 | 准确App授权路径、两项原生granted、显式重启成功、偏好/开关随既有owner落盘、无悬空操作或旧SDK按钮 |
| CU-E03 | 非mac或低版本/资源缺失/remote           | 查看设置                                                                      | 明确不可用，由资源/组件定向tests覆盖；不以本机Electron通过代替其他OS真实运行                    |

GUI路径不调用模型，provider请求预期0，不连接真实用户账号；所有配置写入WDIO临时HOME。原生截图/AX/click/keyboard与跨连接lease另由受控Cocoa fixture和真实native socket验收，不能用组件mock替代。
