从安装到进阶：模型接入、自动化、远程控制与分享。

快速上手

  1. 安装：从下载页获取对应平台安装包。Linux AppImage 需 chmod +x 后运行；macOS 首次打开未签名包如遇 Gatekeeper 拦截，执行 xattr -cr /Applications/Mikiko.app。
  2. 登录账号：首次启动按引导登录 MikikoCC 账号（或在设置 → Mikiko 网关绑定自建 Sub2API 站点），API 密钥与模型列表会自动同步。
  3. 选择模型：在会话输入框的模型选择器里挑选模型与推理档位；模型能力（上下文窗口、支持档位）由智能配置自动对齐，也可在设置中手动覆盖。
  4. 开始任务：直接描述需求，或把项目文件夹拖入窗口建立工作区。Agent 会在授权范围内读写文件、执行命令并汇报进度。

模型与供应商

Mikiko 的模型体系分三层：

  • 账号套餐：MikikoCC / Sub2API 站点登录后自动为每个 API 密钥投影一个个人供应商，密钥、模型清单与额度自动同步。
  • 自定义供应商：任意 OpenAI / Anthropic 兼容端点，可配置 API 格式（chat-completions / responses / anthropic-messages）、Base URL 与密钥。
  • 智能配置：按「模型 ID + API 格式」自动匹配推荐配置（上下文窗口、输入格式、推理档位与请求参数映射），推荐由 Mikiko 云端持续更新；手动修改过的字段转为手动管理，不再被覆盖。

推理档位按模型实际支持情况提供 low / medium / high / xhigh / max 或开关型两档；在模型编辑页可查看与调整档位列表和参数映射表达式。

工作流与自动化

  • 动态工作流：在「工作流」标签用自然语言描述多步流程，Agent 会编排执行并在 GUI 中呈现每步状态，可中途介入调整。
  • 闲时任务：适合额度敏感的重活（大批量重构、依赖升级、巡检）。任务进入闲时队列，在计划时段自动执行，完成后桌面与手机都会收到结果通知。

手机远程控制

在桌面端登录后，手机浏览器打开配对链接即可接入当前会话：查看任务进度、审批文件修改与命令执行、继续对话。实时链路（桌面在线）与恢复链路（断线重连）分离保障，网络抖动后会话不丢。

远控功能可通过配置文件整体启停；连接与断开均有明确的秒级终态反馈。

对话分享

会话右键 → 分享，选择访问模式：

  • 公开只读：任何人可通过链接查看。
  • 公开可导入：接收方在本地导入并继续对话（续聊发生在导入者本地，原始会话不受影响）。

分享服务运行在自托管的 agent.mikiko.ai 上；附件（文档、图片等）随分享一起托管，7 天后自动过期。

更新与维护

  • 自动更新：默认开启，清单与安装包均来自自建更新服务（agent-update / agent-dl），可在设置中检查更新或切换 stable / preview 通道。
  • 强更保障：重大不兼容版本会通过强更配置提示升级，避免旧版本连接异常。
  • 数据位置：本地数据位于 ~/.mikiko/v2；「帮助 → 导出日志」可一键收集排障材料。

常见问题

  • 模型请求报「推理档位不支持」？该模型的档位配置与上游实际支持不一致。在设置 → 模型供应商中编辑该模型，把档位调整为上游支持的取值（如 low/medium/high），或等待智能配置热更。
  • macOS 提示「无法验证开发者」？安装包未做公证签名，执行 xattr -cr /Applications/Mikiko.app 后重新打开。
  • 手机远控连不上？确认桌面端在线且远控开关开启；两端网络不需要同一局域网，但需要都能访问中继服务。
  • 如何完全离线使用？模型请求本身直达供应商端点；智能配置与更新检查出网失败时会回落本地内置数据，不影响日常使用。
