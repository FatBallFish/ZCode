Capabilities

为长期使用而设计

不是聊天窗口，是可以每天挂着跑的生产工具。

◈多供应商模型管理

MikikoCC / Sub2API 中转站一键登录，密钥与模型自动同步；自定义供应商、API 格式与推理档位全可配，智能配置持续跟进。

⚙工作流与自动化

GUI 动态工作流编排多步任务；闲时任务按计划排队执行，把重活交给深夜的额度。

◐手机远程控制

手机随时接入桌面会话：审批权限、跟进任务、断线恢复。实时链路与恢复链路分离保障，体验不打折。

↗自托管对话分享

一键生成分享链接，接收端本地导入续聊。分享服务运行在你自己的 agent.mikiko.ai 基础设施上。
