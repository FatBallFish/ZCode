Capabilities

Built for daily heavy use

Not a chat window — a production tool you keep running.

◈Multi-provider models

One-click sign-in for MikikoCC / Sub2API gateways with automatic key and model sync; fully configurable custom providers, API formats and reasoning levels.

⚙Workflows & automation

Compose multi-step tasks in the GUI workflow editor; off-peak automation queues heavy jobs into cheap night hours.

◐Mobile remote control

Take over desktop sessions from your phone: approve permissions, follow tasks, recover from drops. Realtime and replayable links are kept strictly separate.

↗Self-hosted sharing

One-click share links with local import & continue. The share service runs on your own agent.mikiko.ai infrastructure.
