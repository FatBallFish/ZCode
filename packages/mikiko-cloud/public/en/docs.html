Quick start

  1. 安装：从Download页获取对应平台安装包。Linux AppImage 需 chmod +x 后运行；macOS 首次打开未签名包如遇 Gatekeeper 拦截，执行 xattr -cr /Applications/Mikiko.app。
  2. 登录账号：首次启动按引导登录 MikikoCC 账号（或在设置 → Mikiko 网关绑定自建 Sub2API 站点），API 密钥与模型列表会自动同步。
  3. 选择模型：在会话输入框的模型选择器里挑选模型与推理档位；模型能力（上下文窗口、支持档位）由智能配置自动对齐，也可在设置中手动覆盖。
  4. 开始任务：直接描述需求，或把项目文件夹拖入窗口建立工作区。Agent 会在授权范围内读写文件、执行命令并汇报进度。

Models & providers

The model system has three layers:

  • 账号套餐：MikikoCC / Sub2API 站点登录后自动为每个 API 密钥投影一个个人供应商，密钥、模型清单与额度自动同步。
  • 自定义供应商：任意 OpenAI / Anthropic 兼容端点，可配置 API 格式（chat-completions / responses / anthropic-messages）、Base URL 与密钥。
  • 智能配置：按「模型 ID + API 格式」自动匹配推荐配置（上下文窗口、输入格式、推理档位与请求参数映射），推荐由 Mikiko 云端持续更新；手动修改过的字段转为手动管理，不再被覆盖。

推理档位按模型实际支持情况提供 low / medium / high / xhigh / max 或开关型两档；在模型编辑页可查看与调整档位列表和参数映射表达式。

Workflows & automation

  • 动态工作流：在「工作流」标签用自然语言描述多步流程，Agent 会编排执行并在 GUI 中呈现每步状态，可中途介入调整。
  • 闲时任务：适合额度敏感的重活（大批量重构、依赖升级、巡检）。任务进入闲时队列，在计划时段自动执行，完成后桌面与手机都会收到结果通知。

Mobile remote control

After signing in on desktop, open the pairing link in a phone browser to attach to the live session: follow progress, approve file edits and commands, keep chatting. Realtime and replayable links are separate; sessions survive network drops.

Remote control can be toggled in a config file; connect and disconnect both give clear sub-second terminal feedback.

Conversation sharing

Right-click a session → Share and pick an access mode:

  • Public read-only: anyone with the link can view.
  • 公开可导入：接收方在本地导入并继续对话（续聊发生在导入者本地，原始会话不受影响）。

分享服务运行在自托管的 agent.mikiko.ai 上；附件（Docs、图片等）随分享一起托管，7 天后自动过期。

Updates & maintenance

  • 自动更新：默认开启，清单与安装包均来自自建更新服务（agent-update / agent-dl），可在设置中检查更新或切换 stable / preview 通道。
  • 强更保障：重大不兼容版本会通过强更配置提示升级，避免旧版本连接异常。
  • 数据位置：本地数据位于 ~/.mikiko/v2；「帮助 → 导出日志」可一键收集排障材料。

FAQ

  • Model request says "unsupported reasoning level"?该模型的档位配置与上游实际支持不一致。在设置 → 模型供应商中编辑该模型，把档位调整为上游支持的取值（如 low/medium/high），或等待智能配置热更。
  • macOS says "cannot verify developer"?安装包未做公证签名，执行 xattr -cr /Applications/Mikiko.app 后重新打开。
  • Phone remote control cannot connect?Make sure the desktop is online with remote control enabled; both sides need access to the relay (same LAN not required).
  • Fully offline usage?Model requests go straight to provider endpoints; smart config and update checks fall back to bundled local data when offline.
